# テスト音声・マイクなし録音・聞き直し

v0.7以降は「2 条件を設定」で録音方法を選び、「3 調査する」で開始し、「4 聞き直し・結果」で再生確認します。録音は明示的に開始した場合だけ行い、マイクや追加ソフトは不要です。Windowsの音声設定や音量は変更しません。

v0.5.0以降は、[PCマイク・スマートフォンで実音を記録する方法](physical-capture.md)も利用できます。デジタル録音だけにノイズが入らない場合の比較に使えます。

## 基本の流れ

v0.7以降は[5画面の使い方](user-guide.md)を使います。調査の開始と録音の開始は一つになっています。

1. 「1 準備する」で新規作成または再開します。
2. 「2 条件を設定 → 音の調べ方」で「テスト音声で調べる（再生＋録音）」を選び、録音元・出力・秒数を設定します。他アプリや通知、またはマイクが拾う周囲の音も録音されることを確認し、チェックを入れます。
3. 「3 調査する」の「テスト音声で調査を開始」を1回押します。テスト音声の再生・録音・比較の観察と状態記録が始まります。最初は小音量で確認してください。
4. ノイズが聞こえたら「ノイズが聞こえた」。比較と録音の両方へ記録します。指定秒数か「終了して結果を記録」で録音と観察を終了し、結果を保存します。
5. 「4 聞き直し・結果 → PCで録音した音」で、保存した録音と聞き直す出力を選び、録音を最後まで再生します。実音・録音・聞こえ方を選び、「照合結果を保存」します。
6. 「元のテスト音を再生」やHDMI等の出力も比較します。聞き直しの出力は調査時の出力と独立して選べ、照合に使った出力名も保存します。

共通音声は、ツールが生成する10秒の固定パターンです。無音、440Hz、左右別の正弦波、複合音、スイープを含み、境界は滑らかにし、ピーク振幅を0.08に抑えています。48000Hz・16bit・ステレオの `reference.wav` を繰り返し再生します。基準音声の識別子とSHA-256を保存するため、同じ元音かを確認できます。

## 問題が起きるアプリの音を録る

「2 条件を設定」で「普段のアプリの音を調べる（録音）」を選びます。「3 調査する」の開始ボタンで録音・観察を開始してから、問題のアプリを選んだ出力で再生してください。ツールの基準音声は流しません。録音はアプリ単独ではなく、その出力全体の音声ミックスです。

Bluetooth等の比較条件も2で設定します。比較を別に開始する操作は不要です。録音の終了は観察の終了も意味し、聞き直しは結果を保存した後の4で行います。これにより、聞き直しの音を調査へ混ぜません。

## 記録される音と、実際に聞こえる音の違い

WASAPIループバックは、Windowsの出力エンドポイントの音声を取得する仕組みです。スピーカーの振動や、3.5mmのアナログ回路以降で発生した電気的なノイズを直接測定するものではありません。**実際にはノイズが聞こえ、録音には入っていない**という結果も重要な証拠で、正常とは判定しません。取得経路・アナログ側・ハードウェア・録音の限界などを次に調べます。

一方、保存WAVの再生でもノイズが聞こえても、故障している再生経路が**再生時に新たに**ノイズを加えている可能性があります。元の基準音と比べ、可能ならHDMIや別PCなど既知の正常な経路でも聞いてください。聞き直し時は出力の共有モード形式に合わせてリサンプリングやチャンネル変換が入る場合があります。原本WAVは取得したネイティブ形式で保存し、書き換えません。

アプリの「保存した録音を再生」「元のテスト音を再生」では、再生前にノイズのない確認済みの出力へ切り替える警告を表示します。同じ出力ならその点も示します。既定の「出力を変更するため戻る」で選び直すか、明示的に「この出力で再生する」を選べます。別の出力や警告への了承を正常の証明にはせず、了承した出力の関係を記録します。報告書HTMLや元ファイルを直接開く場合はダイアログを通らないので、再生前に自分で経路を確認してください。

保護された音声、排他モード、出力切り替え、音声サービス停止などにより取得できない場合があります。取得失敗、中断、パケットなし、音声データの不連続フラグを保存します。最初のパケットの不連続には開始時の遷移も含まれ、フラグだけを可聴ノイズや原因の自動検出とは扱いません。音声が供給されない時間帯は時刻合わせの無音で補い、補ったフレーム数を記録します。録音が無音であることも正常の証明にはなりません。

## 保存・持ち帰り

```text
data/sessions/<実行ID>/
  session.json
  report.html
  audio/<録音ID>/
    reference.wav   # 共通音声モードだけ
    loopback.wav    # 取得した音声の原本
```

録音を使った調査では、**session.jsonだけでなくaudioフォルダーを含むセッションフォルダー一式**を持ち帰ってください。「記録を再開」で別の場所のJSONを開くと、同じ場所にある対応WAVもローカルのセッションへコピーします。元のファイルを変更せず、記録されたハッシュと異なるファイルを黙って上書きしません。WAVがない場合は聞き直しできない旨を表示します。

WAVには他アプリの音声や通知も含まれ得ます。録音・ログはローカルの `data/` に保存し、自動送信しません。共有前に内容を確認し、公開GitHubへ調査音声を追加しないでください。
