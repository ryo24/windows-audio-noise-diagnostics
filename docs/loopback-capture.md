# テスト音声・マイクなし録音・聞き直し

v0.4.0以降の「テスト音声・録音・聞き直し」タブを使います。録音は明示的に開始した場合だけ行い、マイクや追加ソフトは不要です。Windowsの音声設定や音量は変更しません。

v0.5.0以降は、[PCマイク・スマートフォンで実音を記録する方法](physical-capture.md)も利用できます。デジタル録音だけにノイズが入らない場合の比較に使えます。

## 基本の流れ

1. `start.cmd`で起動し、「PC情報を収集・新規調査」または「記録を再開」を選びます。
2. 音声タブで「出力一覧を取得」を押し、実際に使っている3.5mm等の出力を選びます。この出力に流れる**他アプリ・通知の音も含まれる**ことを確認してチェックします。
3. 「共通テスト音声を再生して録音」を選び、小さめの音量から「再生・録音を開始」。標準は60秒、最大300秒／音声データ256MBで停止します。音量は自分で調整してください。
4. 実際にノイズが聞こえたら「いまノイズが聞こえた」を押します。通常の比較テスト中なら、そのテストのノイズ時刻と録音側の時刻の両方に記録します。
5. 停止後、「録音を再生」で保存したWAVを最後まで聞き直します。「実際の出力のノイズ」「録音のノイズ」「聞こえ方が同じか」を別々に選び、「照合結果を保存」してください。途中までの再生は全体の確認済みにしません。
6. 「元のテスト音を再生」や、HDMIなど別の正常な出力での再生も比較します。録音を再生する出力は同じ一覧から変更でき、照合に使った出力名も保存されます。

共通音声は、ツールが生成する10秒の固定パターンです。無音、440Hz、左右別の正弦波、複合音、スイープを含み、境界は滑らかにし、ピーク振幅を0.08に抑えています。48000Hz・16bit・ステレオの `reference.wav` を繰り返し再生します。基準音声の識別子とSHA-256を保存するため、同じ元音かを確認できます。

## 問題が起きるアプリの音を録る

「他アプリの音を録音（テスト音なし）」を選ぶと、ツールの基準音声は流しません。問題のアプリを、録音先として選んだものと同じ出力へ設定して再生してください。録音はアプリ単独ではなく、その出力全体の音声ミックスです。アプリごとに出力先が違う場合は取得対象も変わります。

Bluetoothなどの条件比較と組み合わせる場合は、通常の「テスト開始」を押してから音声タブで録音を開始します。録音中は出力先や機器の条件を変えず、変更するなら停止して別テストにします。音声録音を停止し、通常の比較テストも終了してから録音を聞き直してください。聞き直しの音を比較テストへ混ぜないため、通常テスト中の再生確認は無効になります。

## 記録される音と、実際に聞こえる音の違い

WASAPIループバックは、Windowsの出力エンドポイントの音声を取得する仕組みです。スピーカーの振動や、3.5mmのアナログ回路以降で発生した電気的なノイズを直接測定するものではありません。**実際にはノイズが聞こえ、録音には入っていない**という結果も重要な証拠で、正常とは判定しません。取得経路・アナログ側・ハードウェア・録音の限界などを次に調べます。

一方、保存WAVの再生でもノイズが聞こえても、故障している再生経路が**再生時に新たに**ノイズを加えている可能性があります。元の基準音と比べ、可能ならHDMIや別PCなど既知の正常な経路でも聞いてください。聞き直し時は出力の共有モード形式に合わせてリサンプリングやチャンネル変換が入る場合があります。原本WAVは取得したネイティブ形式で保存し、書き換えません。

保護された音声、排他モード、出力切り替え、音声サービス停止などにより取得できない場合があります。取得失敗、中断、パケットなし、音声データの不連続フラグを保存します。最初のパケットの不連続には開始時の遷移も含まれ、フラグだけを可聴ノイズや原因の自動検出とは扱いません。音声が供給されない時間帯は時刻合わせの無音で補い、補ったフレーム数を記録します。録音が無音であることも正常の証明にはなりません。

## 保存・持ち帰り

```text
data/sessions/<実行ID>/
  session.json
  report.html
  audio/<録音ID>/
    reference.wav   # 共通音声モードだけ
    loopback.wav    # 取得した音声の原本
```

録音を使った調査では、**session.jsonだけでなくaudioフォルダーを含むセッションフォルダー一式**を持ち帰ってください。「記録を再開」で別の場所のJSONを開くと、同じ場所にある対応WAVもローカルのセッションへコピーします。元のファイルを変更せず、記録されたハッシュと異なるファイルを黙って上書きしません。WAVがない場合は聞き直しできない旨を表示します。

WAVには他アプリの音声や通知も含まれ得ます。録音・ログはローカルの `data/` に保存し、自動送信しません。共有前に内容を確認し、公開GitHubへ調査音声を追加しないでください。
