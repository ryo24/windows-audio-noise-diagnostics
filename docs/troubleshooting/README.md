# 音声ノイズの切り分けガイド

Windows PCの音声ノイズを、接続・給電・再生設定などの条件を一つずつ変えて調べる手順集です。調査ツールの使い方は[プロジェクトのREADME](../../README.md)を参照してください。

## プルリクエストで手順を追加・改善する

同じ比較が掲載されていればそのページを更新します。新しい比較は `docs/troubleshooting/` にMarkdownで追加し、上の一覧にリンクを加えます。

手順には、別のPCでも試せるように次の情報を書きます。

- **対象と用意するもの** — どのような症状・接続で使う手順か。
- **比較方法** — 何を変え、何を揃えるか。設定を変える場合は元に戻す方法も添える。
- **結果の読み方** — 観察結果ごとに候補がどう絞れるか。判断が残る場合は次の比較を書く。

プルリクエストの取り込み先はdevelopにします。説明には、実機で試した条件と観察結果、または参照した一次資料を添えると確認しやすくなります。機種名に依存する情報は、その機種での観察として扱います。公開する内容には必要な条件と結果の要約を使い、持ち帰ったログやZIPは手元の [`external-results/`](../../external-results/) に保管します。
