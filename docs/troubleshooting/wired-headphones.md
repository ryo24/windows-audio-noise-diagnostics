# 有線イヤホンを3.5mm端子に直結する

PCの3.5mm端子につないだスピーカーでノイズが出たときに使います。同じ端子に有線イヤホンやヘッドホンを直接つなぎ、スピーカーのケーブル・入力回路・給電を経由しない状態で、同じ症状が聞こえるかを確かめます。

## 比較する

1. スピーカーでノイズが出ている状態を記録します。再生アプリ、音源、PCの出力先、スピーカーの給電先を控えます。
2. PCの音量を下げ、スピーカーの3.5mmプラグを抜き、同じ端子に有線イヤホンを直結します。USB給電のスピーカーなら給電ケーブルはつないだままにすると、PCのUSB接続構成を揃えられます。
3. 同じアプリで同じ箇所を再生し、聴き取れる音量で、元と同じ種類のノイズが出るかを確かめます。再起動やBluetooth設定の変更は比較を終えてから行います。
4. 音量を下げてからスピーカーへ戻し、元の音量と条件でノイズが再発するかを確認します。各条件の観察時間と、出力先の表示名が接続時に切り替わったかも記録します。

調査ツールを使う場合は、イヤホンでの観察を **4. 有線イヤホンで比較** で別のテストとして記録できます。

## 結果を読む

| 観察結果 | 次に調べる箇所 |
| --- | --- |
| イヤホンでも同じノイズが出る | PC側の3.5mm出力経路を優先する。音声設定・ドライバーと、端子や回路が候補に残る。 |
| イヤホンで止まり、スピーカーへ戻すと再発する | スピーカーのアナログ入力・ケーブル・給電や、PCとの組み合わせを優先する。同じスピーカーを別の音源につなぐか、給電先だけを変えると候補をさらに絞れる。 |
| スピーカーへ戻しても再発しない | 発生中にもう一度比較する。プラグの挿し直しや時間経過で症状が変化した可能性がある。 |
