# 画面の使い方（v0.7以降）

「準備 → 条件設定 → 調査 → 聞き直し・結果 → 書き出し」の5画面を使います。**調査の開始は「3 調査する」のボタン一つだけ**です。録音する方式なら、録音・観察・Bluetooth等の状態記録を一緒に開始します。録音用の別の開始ボタンはありません。

## 1 準備する

分かる範囲で機器・給電・確認済みの症状を入力し、「PC情報を収集して新規作成」を押します。取得が終わると「2 条件を設定」へ進みます。C-Statesは任意の記録で、BIOSの確認や変更は必要ありません。以前の記録を使う場合は「保存した記録を再開」でsession.jsonを選びます。

## 2 条件を設定

最初の「音の調べ方」で、次のいずれかを選びます。

| 調べ方 | 開始ボタンを押すと行うこと | 自分で行うこと |
| --- | --- | --- |
| テスト音声で調べる（再生＋録音） | 共通のテスト音声を再生し、音声と状態を記録 | 音量を小さくして、聞こえ方を観察 |
| 普段のアプリの音を調べる（録音） | 音声と状態を記録。テスト音声は流さない | 問題のアプリを、選んだ出力へ設定して再生 |
| 録音せず、耳で確認する | ノイズボタンの時刻・構成・状態だけを記録 | 普段の音を再生して観察。録音の許可は不要 |

録音ありの場合は、Windows内部の音かPCマイクを選び、出力・マイク・秒数を確認します。

### 「この範囲の音を録音してよい」は何をするもの？

録音に含まれる音を理解し、録音してよいことを示すチェック欄です。「すでに音が録れるかテストした」という意味ではなく、事前の録音テストは不要です。

1. **Windows内部の音**なら、選んだ出力から流れるテスト音声・他アプリの動画・通知なども録音されます。入れたくない音の再生を止めます。**マイク**なら、周囲の会話なども入るため、録音してよい環境か確認します。
2. 問題なければ、**「この範囲の音を録音してよい」の左の四角をクリック**してチェックを入れます。文字の部分をクリックしても切り替えられます。
3. **「3 調査する」へ進んで開始ボタンを押します。** チェックだけでは録音や再生は始まりません。出力等の準備が済んでいれば、チェックにより開始ボタンを押せるようになります。

方式やデバイスを変えたときはチェックを外し、確認し直すようにします。録音なしでは確認不要と表示し、このチェックを無効にします。

「比較する条件」で接続・給電・再生アプリ・変更点を、「Bluetooth（任意）」と「再生条件のメモ」で必要な追加条件を記入します。調査時の出力名と手動で申告した接続は別々の項目です。「3 調査画面へ」を押してもまだ記録は始まりません。

内部録音に現れない変化を調べる場合は「次の切り分け」でUSB＋Audio、良好な実音対照、形式変更を選べます。「共通テスト音声・30秒に設定」で準備し、実際のWindows出力を選びます。比較先は過去の調査の一覧から選択できます。USB付きだけは追加の取得範囲を了承すると、共通の開始で管理者権限の確認を経て取得し、共通の終了で停止保存します。先頭に入る短い符号音は10秒区間の位置合わせ用です。[追加調査の手順](usb-follow-up.md)を参照してください。

再起動等で回復した場合は「状態変化・回復条件を比較」で直前の操作と発生状態を記録します。再起動と機器の入れ直しを両方行った場合は「複数の操作」を選びます。「別の記録から選ぶ」で別セッションの調査も比較先へ指定できます。既に得られた正常録音の撮り直しは必須ではありません。

## 3 調査する

上部の条件と案内を確認し、**開始ボタンを1回**押します。ボタン名は調べ方に合わせて変わります。

- 「テスト音声で調査を開始」
- 「アプリ音声の録音・調査を開始」
- 「録音せずに調査を開始」

どれも同じ場所にある一つのボタンです。開始できない場合は、この画面の案内に不足している準備を表示します。調査中は条件変更と再度の開始を無効にし、「ノイズが聞こえた」と「終了して結果を記録」を使います。ノイズボタンは、比較記録と現在の録音の両方へ関連づけて記録します。

録音ありでは、指定した秒数・サイズ上限・録音失敗による停止時に観察も終了し、保存後に結果入力へ進みます。途中で終える場合も「終了して結果を記録」一つで録音と観察を止めます。録音なしでは10分を目安に手動で終了します。終了後の情報取得や結果入力の時間は観察時間に追加しません。

結果の「再現せず・改善・変化なし・悪化」と備考を保存すると、「4 聞き直し・結果」へ進みます。結果入力を閉じた場合は結果未確定の中断記録として残し、録音を再開することはありません。録音失敗や短い無発生を正常・解決の証拠にはしません。

「スマホをつなぐ（任意）」は、実際のスピーカー音を追加記録するための受信機能です。「スマホからの受信を開く」は調査や録音の開始操作とは別で、送信先を開くだけです。QRを読み、端末で録音・撮影・ファイル選択して送信します。詳細は[スマートフォンの手順](physical-capture.md)を参照してください。

PCが有線LANでも利用できます。ページが開かない場合は、同じ最新URLをスマホの別ブラウザーで比較した後、PCで「接続診断を保存」を押し、結果とエラー文を保存します。選択したLAN内IP・ポートも記録とZIPに入ります。HTTPコードがない接続失敗でも保存できます。[Firefox Beta／Androidの診断手順](phone-connection-troubleshooting.md)にUSBでエラーを調べる方法があります。接続を待たずに、スマホのカメラで撮影した動画をUSBでPCへコピーして「ファイルを取り込む」から追加することもできます。

スマホで「付近のデバイス」「ローカルネットワーク」への許可が出たら、このPCへの接続を許可してください。拒否済みならAndroidのChromeの権限やサイトの権限を確認します（表示項目は版によって異なります）。マイク許可とは別です。ページが開いても送信だけ失敗する場合は、スマホで「送信ログを保存」し、JSONをUSB等でPCへコピーします。「接続診断を保存 → スマホの送信ログを選択」で選び、診断を保存してZIPを書き出します。

「詳細トレース（任意）」も追加のWPR取得です。通常は操作不要です。利用する場合は説明を確認し、ノイズは上の共通ボタンで記録します。[詳細調査の手順](reproduction-evidence.md)に取得範囲と制限があります。

WPRの停止では「要求の受付待ち → ETL保存中 → 停止・保存完了」を表示します。待機中は経過秒数を更新し、応答が止まった場合は未確認と表示します。「WPRの保存先を開く」で状態・終了コード・ETLを確認できます。要求を送っただけで停止完了とは扱いません。

## 4 聞き直し・結果

PC録音がある場合は「PCで録音した音」、録音なしの調査なら「比較の結果・テストID」を開きます。

PC録音の確認は画面の①〜③の順です。保存した録音を選び、**聞き直す出力**を選択して「保存した録音を再生」を押します。この出力は調査・録音時の出力とは別に選べます。可能ならHDMIなど正常な経路でも確認してください。ここで再生しても調査は始まりません。途中停止は「聞き直しを停止」です。

再生前に出力の確認が出ます。**ノイズが出ないと確認済みの出力**を使ってください。「出力を変更するため戻る」で戻って出力を選び直すか、「この出力で再生する」で続けられます。録音時と同じ出力なら、その点も警告します。「元のテスト音を再生」とスマホ等の実音の再生も同様です。別出力を選んだことや警告の了承は、正常である証拠にはしません。報告書のHTMLから直接再生する場合はこのダイアログが出ないので、自分で出力を確認してください。

録音を最後まで聞くと照合結果を保存できます。調査中の実音、録音の音、両者が同じかを別々に記録します。「元のテスト音を再生」は比較用で、録音を最後まで確認した代わりにはなりません。詳細は[録音の仕様](loopback-capture.md)を参照してください。

スマートフォン等の記録は「スマホなどの実音」で一覧から再生し、手動の確認結果を保存します。受信操作と再生確認は別の画面にあります。

次の条件を試す場合は「2 条件を設定」へ戻ります。同じセッションに別の比較として追加し、以前の録音・結果は保持します。

## 5 書き出す

報告書を開く、記録フォルダーを開く、ZIPを書き出す操作をまとめています。調査・録音・受信・詳細トレース・聞き直しが終わり、情報取得が完了すると書き出せます。待つ理由もこの画面に表示します。

「ZIPを書き出して場所を開く」を押すと、現在のセッションのログ・録音・動画をまとめ、エクスプローラーでZIPを選択します。通常は詳細ETLを含めず、必要な場合だけチェックします。保存先・受け取り先・エージェント解析は[データ管理の手順](data-workflow.md)を参照してください。

## ボタンを押せないとき

| 状態 | 次の操作 |
| --- | --- |
| 記録が未作成 | 1で新規作成・再開 |
| 録音先や録音範囲の確認が不足 | 2の「音の調べ方」で選択・確認 |
| 構成・関連情報の取得中 | 完了を待つ。ノイズボタンと終了要求は調査中なら使える |
| 保存した録音がない | 録音なしの調査なら「比較の結果・テストID」を確認 |
| 照合結果を保存できない | 保存した録音を最後まで再生 |
| ZIPを書き出せない | 5の案内を確認し、調査・受信・WPR・聞き直しを終了 |

途中でアプリを閉じる場合は、録音ファイルを確定して状態記録を保存し、実行中の調査を中断として残します。取得中は終了まで待ち、強制終了を避けてください。
