# 外から受け取った調査データ

ここには公開しない調査原本と解析結果を置きます。使い方は[データの書き出し・受け取り・エージェント解析](../docs/data-workflow.md)を参照してください。

- `inbox/`：受け取ったZIPをそのまま置く場所。追記専用として扱い、原本を編集・削除しません。
- `cases/<case>/imports/<ZIPのSHA-256>/`：取り込みスクリプトが原本コピー・展開データ・受領記録を保存する場所。
- `cases/<case>/analysis/`：エージェントが解析メモやグラフを作る場所。原本とは分離します。

ZIPを置いただけでは実行・展開・送信されません。原本ZIP・展開データ・解析結果はGit管理対象外です。公開するのはこの案内と空フォルダー用の`.gitkeep`だけです。
